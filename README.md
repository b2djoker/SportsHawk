# SportsHawk

React web app for a football player development product focused on Indian grassroots players, daily training habits, gamification, and a physical assessment center pipeline.

## Current Scope

- Vite + React project structure
- Tailwind CSS setup
- React Router routes
- Player onboarding flow
- Profile creation fields: name, age, position, city, profile photo upload
- Player dashboard placeholder after profile creation

## Run Locally

Install dependencies, then start the dev server:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.
